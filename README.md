- **⚡ Blazing Fast Performance:** Optimized with Vite and modern React patterns.

## 🛠️ Tech Stack

### Frontend & Rendering
- **Framework:** React 18
- **Build Tool:** Vite
- **Language:** TypeScript
- **Routing:** React Router DOM v6

### Styling & Components
- **Styling:** Tailwind CSS
- **Component Library:** shadcn/ui (Radix UI)
- **Icons:** Lucide React
- **Animations:** Tailwind Animate, Framer Motion

### Utilities & Data
- **State Management:** React Hooks
- **GitHub Data:** react-github-calendar

## 🚀 Getting Started

Follow these steps to set up the project locally:

### 1. Prerequisites
- Node.js (v18.0.0 or higher)
- npm or yarn

### 2. Installation

```bash
# Clone the repository
git clone https://github.com/Prathmesh125/PD_Portfolio.git

# Navigate to the project directory
cd PD_Portfolio

# Install dependencies
npm install
```

### 3. Running Locally

```bash
# Start development server
npm run dev
```

Open `http://localhost:8080` in your browser.

### 4. Build for Production

```bash
npm run build
```

## 📂 Project Structure

├── pages/          # layout pages (Index.tsx)
